# 场景二：跟老板聊天（上级 / 老师 / 甲方负责人，向上沟通）

核心命题：老板买单的是**省心和结果确定性**。沟通的本质不是"会来事"，是高效传递信息、对齐预期、建立靠谱感。

## 底层原则

1. **结论先行。** 先说结果和结论，再补细节；日常沟通控制在 3 分钟内讲完。老板的时间比你的面子贵。
2. **选择题代替问答题。** 永远带着方案去提问：先讲自己的分析和备选方案，再请老板拍板。哪怕方案被否，老板也会记住"这人能想办法、能帮我省心"。
3. **主动同步，风险前置。** 关键节点主动汇报进度和风险，别等项目结束才给"惊喜或惊吓"。方向错了能及时纠偏，你的进展也能"被看见"。
4. **看人下菜。** 结果导向型老板多讲数据和进度；细节型老板多讲执行步骤和预案。
5. **选对渠道。** 日常进度用即时消息；复杂、敏感的事当面聊；需要留痕的发邮件/正式文档。

## 场景模板

### 汇报进度
「目前完成了 XX，下一步计划做 XX，需要你确认的是 XX。」
- 三段缺一不可：已完成（给确定性）、下一步（表主动性）、待确认（把决策权交回老板）。

### 汇报成果（用数据，不用形容词）
- ❌「我这个月跑客户跑得挺多的」
- ✅「本月拜访 15 家新客户，3 家达成初步意向，预计带来营收 XX 万，转化率比上季度提升 10%」
- 老板给资源和机会的理由永远是"能带来真金白银"，不是"看起来很努力"。

### 求助 / 卡住时
「我卡在 XX 环节，试过 A 和 B 两个方案，A 的问题是…，B 的问题是…，你看优先推进哪个方向？」
- 关键是证明你已经穷尽过自己的办法，求助的是决策，不是甩锅。

### 提不同意见
- 私下说，不当众反驳。
- 先肯定共识（"大方向我完全同意"），再用数据和事实补充，最后给出替代方案而不是单纯否定。

### 争取资源
「价值—支持—预期结果」三段：这件事做成值多少 → 需要什么支持 → 预计什么时候出什么结果。

### 接任务
- 听完用"一、二、三"复述要点给老板确认——同时查漏（他补上漏说的）、防误解、表态度。
- 当场确认三件事：交付标准、截止时间、优先级（和手头其他事冲突时砍哪个）。

## 被批评 / 被指责时

1. **不马上接话。** 听完，停顿几秒，对方气势先减一半。
2. **先接情绪，后谈事实。** 平静复述他的核心诉求：「你是觉得 XX 没解决，对吗？」让他确认被听见，降温后再谈事实。
3. **不自证。** 不连环解释"我做了哪些哪些"——解释就是掩饰。需要说明时只给事实和证据，一次讲清。
4. **借规则说话。** 争议涉及流程时，用制度、文件、既定安排回应，把个人对抗转成规则问题。
5. 微信文字场景被骂：先回一句「好的，我马上处理/我看一下」接住，其他话一概不急着说，事后用结果汇报收尾。

## 雷区清单

1. 只抱怨不给方案——直接被打上"能力不足"标签。
2. 闲聊八卦：不聊同事隐私、不吐槽公司、不传话。
3. 情绪上头硬刚、当众顶撞——赢了嘴仗，输了信任。
4. 惊喜式汇报：憋大招到最后才说，方向错了就是全盘返工。
5. 模糊表述："差不多""快了""应该没问题"——换成具体数字、时间和状态。
6. 越级和抢功：功劳归属说清，越级汇报是大忌（除非老板明确授权）。

## 关系维护

- 主动求反馈：「这个月的工作，您觉得我哪里可以做得更好？」——不是示弱，是拿到老板真实期望、校准努力方向的最短路径。
- 让进步"被看见"是管理预期，不是炫耀：定期同步 + 数据锚定 + 复盘小结，三件套循环即可。
