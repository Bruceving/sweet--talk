# 如何跟老板、女朋友、客户谈恋爱

**sweet-talk** —— 一个中文聊天沟通 Skill，喂给你的 AI agent，它就能替你把天聊好。

跟老板谈、跟女朋友谈、跟客户谈——表面上是三种聊天，本质是同一件事：

> **搞清对方要什么，用最低的沟通成本，给他确定性。**
> 女朋友要情绪的确定性，老板要结果的确定性，客户要靠谱的确定性，商务伙伴要利益的确定性。

## 它能干什么

把聊天记录或对方的一句话丢给 agent，它会：

1. 先判断对象是谁（女生 / 老板 / 客户 / 商务伙伴），加载对应的打法文件
2. 判断当前阶段（破冰、升温、僵持、临门一脚、收尾）和对方的真实意图
3. 产出**可以直接复制发送**的回复草稿；涉及报价、承诺等敏感动作时，会先标注"需确认"再给稿

## 部分精华

- **汇报模板**：「目前完成了 XX，下一步计划做 XX，需要你确认的是 XX。」
- **客户四问**：问目标 → 问现状 → 问限制 → 问决策，四问没问清不报价。
- **报价后沉默 10 秒**：报完价别解释、别自降，等对方先开口。
- **转介绍闭环**：客户介绍人，当天反馈进展，成交立刻兑现感谢——被介绍人一句"靠谱"，比你十句谢谢值钱。
- **女生聊天铁律**：对话是乒乓球不是演讲；夸具体细节不夸泛泛；话术只是放大器，专注于自己、有闪光点才是本体。

## 使用方式

兼容 Claude Code / DeepSeek harness 等支持 Skill 格式的 agent 框架：

1. 把整个 `sweet-talk` 文件夹放进你的 skills 目录
2. 正常对话即可触发：把聊天记录发给 agent，说"帮我回这句"；也可以显式调用这个 skill
3. 想改成你自己的风格：直接改 `references/` 里的文件，agent 下次加载即生效
